# Rock Paper Scissors Game (Python)

This is a command-line Rock Paper Scissors game developed using Python.  
The project demonstrates fundamental programming concepts including conditional statements, lists, user input handling, and random number generation.

---

## Overview

The application allows a user to play Rock Paper Scissors against the computer.  
The computer randomly selects a move, and the program determines the winner based on standard game rules.

---

## Features

- ASCII representation of Rock, Paper, and Scissors
- User vs Computer gameplay
- Random move generation using Python's built-in random module
- Input validation for invalid selections
- Clear win, lose, and draw outcomes
- Structured and readable code

---

## Technologies Used

- Python 3
- random module
